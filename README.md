# a-merry-fx-mesh

SDF Based Fragment Shader experiments for 2025s new year

To create your own, click the icon in the bottom right and edit as much as you want!
State is stored in the URL. You can freely share the URL with other people and they will see the exact same thing as you will see!

## no database is hurt by using this app

Uses my url-safe-bitpacking library to be able to store the whole state in the URL! I don't store anything of what you are doing! The whole state of the application is handled front-end and stored in the URL (after the hash).
